## 它解决什么问题

考研备考里最耗人的不是「没有资料」，而是四件事：

1. **题目看懂了答案，但不懂思路从哪来** —— 研来讲解时先讲「为什么要这样想」，再推导。
2. **错题记了但不会归因** —— 研来定位到你**出错的那一步**，并归类错因（概念？公式？审题？思路？），统计出你最常掉坑的环节。
3. **计划定了但没人管** —— 研来把作息写进时间规划，到点弹窗、系统通知、提示音一起提醒，窗口收进托盘也照常工作。
4. **资料散落各处** —— 导入教材真题后，提问会自动检索你的资料并**标注出处**，而不是凭空作答。

## 三分钟上手

### 安装

下载已发布版本对应的 `Yanlai-<版本>-Setup-x64.exe` 运行安装，或使用 `Yanlai-<版本>-Portable-x64.exe` 免安装版。安装包构建不等同于 NSIS 安装/卸载行为已验收；未覆盖范围见验证记录，旧 `release/` 文件不能作为本次正式产物的证据。

### 配置模型（必做）

启动后点左下角齿轮，或按 <kbd>Ctrl</kbd>+<kbd>,</kbd> → **模型与 API**：

| 字段 | 填什么 |
|---|---|
| 服务预设 | 选一个，或留「自定义」 |
| Base URL | 兼容 OpenAI 的接口根路径，通常以 `/v1` 结尾 |
| API Key | 你的密钥（本地模型可留空） |
| 模型名称 | 如 `deepseek-chat`、`gpt-4o`、`qwen-plus` |

点 **测试连接** 确认（只拉模型列表，不消耗生成额度）。

**常见服务地址：**

| 服务 | Base URL | 推荐模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat`（便宜好用）、`deepseek-reasoner`（带推理） |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o`、`gpt-4o-mini` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus`、`qwen-vl-max`（视觉） |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash`、`glm-4v`（视觉） |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:14b` |

> **想用「截图讲题」**，模型需要支持视觉输入：`gpt-4o`、`qwen-vl-max`、`glm-4v`、`claude-3.5-sonnet` 等。
> **完全免费方案**：装 [Ollama](https://ollama.com)，执行 `ollama pull qwen2.5:14b`，Base URL 填 `http://127.0.0.1:11434/v1`，Key 随便填。

### 开始学习

三种最快的开始方式：

- **截图讲题**：<kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> 截图 → 在输入框 <kbd>Ctrl</kbd>+<kbd>V</kbd> → 发送
- **贴错题**：把题目、你的解答、正确答案一起发来 → 自动分析错因并记入错题本
- **点功能条**：底部选「讲解题目 / 类比出题 / 按题型出整卷 / 整理知识点」等模式

## 核心功能

### 十二种学习模式

切换模式会换一套**专门的系统提示词与工具集**，不是简单换个前缀。

| 模式 | 适合场景 | 它做了什么特别的事 |
|---|---|---|
| **自由问答** | 任何学习问题 | 先判断你的真实意图，再决定回答深度 |
| **讲解题目** | 发题目要完整讲解 | 六段式：考点识别 → **思路先行** → 分步推导 → 易错提醒 → 知识点回扣 → 变式检验 |
| **类比出题** | 要同源变式练习 | 先拆原题骨架，再按 5 个维度变形，标明哪些与原题同构 |
| **按题型出整卷** | 要一份完整模拟卷 | 按真题题型/分值/难度分布出卷，附答案、解析、考点分布表 |
| **总结大纲** | 整理科目大纲 | 多级结构 + 重要度星级（★★★必考）+ 考频量化 + 学习顺序 |
| **整理知识点** | 把材料结构化 | 每块含定义/条件/公式/直觉/用法/常见错误/记忆锚点 |
| **错题分析** | 发错题+你的解答 | 定位错误步骤 → 归类错因 → 正解 → **对照分析岔路口** → 防复发建议 |
| **学习计划** | 制定可执行计划 | 分阶段（基础/强化/冲刺），**保存为未启用方案，检查后手动选用** |
| **背诵卡片** | 把内容做成卡片 | 一卡一知识点，自动写入间隔重复队列 |
| **复盘总结** | 阶段性总结 | 读取你的错题数据，按提分收益排序薄弱点，给出遗忘曲线复习安排 |
| **作文批改** | 英语作文/政治大题 | 按考研评分档打分 → 逐句精批表格 → 保留你风格的提分版 |
| **长难句翻译** | 英语长难句 | 断句 → 找主干 → 结构树 → 直译+润色 → **点出命题方式** |

**讲题示例**（「讲解题目」模式的实际结构）：

```
1. 题目识别   —— 一句话点明考点与题型
2. 思路先行   —— 为什么要这样想，从哪个条件切入（学生最缺的部分）
3. 详细解答   —— 分步推导，每步注明依据；需要图形时自动绘图
4. 易错提醒   —— 本题的典型陷阱
5. 知识点回扣 —— 考纲定位与考频
6. 变式检验   —— 同源变式题，只给题不给答案
```

> 如果你**已经做过这道题**，把解答一起发来，研来会逐行检查，指出**第一个出错的位置**并分析根因——这比看标准答案有用得多。

### 数学绘图

涉及函数图像、几何关系、分布曲线、积分面积时，研来会**自动调用绘图能力**，图像直接显示在对话里。

支持：
- **显函数** `x^2 - 2*x + 1`、`sin(x)/x`
- **参数方程** `x = cos(t), y = sin(t)`
- **极坐标** `r = 2*cos(t)`
- **多曲线对比**、**散点标注**、**辅助虚线**（渐近线/切线）
- **填充区域**（积分面积），并给出数值积分结果
- **自动标注**零点、极值点

图像是**矢量 SVG**，缩放不糊，也能直接嵌入导出的 Word / PDF。

支持 LaTeX 风格输入：`\frac{1}{2}`、`\sqrt{x}`、`\pi`、`x^{2}` 都能解析。

**内置计算工具**：求值、化简、求导（含高阶）、数值求解方程、数值积分、求和、矩阵运算（行列式/逆/特征值）、统计量。

### 知识库

导入你自己的教材、笔记、真题，回答会**先检索你的资料**并标注 `[来源: 文件名]`。

**支持格式**：PDF、Word（docx/doc）、Excel（xlsx/xls）、Markdown、TXT、CSV、JSON、题目图片。

导入方式：
- 「知识库」页拖入文件或文件夹，或点「导入资料」
- **「导入文件夹」** 递归导入整个目录（含子文件夹），适合整章 / 整本书 / 资料包
- 「粘贴文本」标签页直接贴笔记
- 在「工作区」页对某个文件点数据库图标
- **命令行批量导入**：`yanlai --import-kb <目录> --subject 科目 --import-kb-exit`
  （`--import-kb-replace` 先清空知识库，不影响对话与错题本）

**检索机制**：本地 BM25（中文二元/三元切分 + 英文分词）
- **零 token 消耗**，可完全离线
- 回答前自动检索，也可在「检索测试」页验证关键词命中
- 片段与标题匹配会加权，重复内容自动去重

**让 AI 帮你整理知识库**：

| 你可以说 | 效果 |
|---|---|
| 基于知识库资料整理一份考纲式知识点大纲，并存回知识库 | 生成结构化大纲并入库 |
| 提取核心公式清单，按章节整理成表格 | 公式速查表 |
| 检查不同资料对同一考点的表述是否矛盾 | 交叉验证，指出缺口 |
| 基于资料生成一批背诵卡片 | 直接进入复习队列 |

**PDF 说明**：自动提取文字层；扫描版 PDF 提不出文字时会提示你改用图片（图片由视觉模型直接读取）。

### 错题本与记忆管理

**自动记录**：当你提交自己做错的解答时，研来会记录题目、你的错解（原样保留，便于看出思维路径）、正确解法、错因分析、错因归类、涉及知识点、难度。

**错因归类体系**（10 类，按根因而非表象）：

```
概念不清   公式记错   计算失误   审题错误   思路偏差
方法不会   知识盲区   时间不足   粗心大意   其他
```

> **为什么要分类错因**：「算错」往往是「公式记错」的结果，「不会做」常常是「概念不清」的表象。
> 把错因归到根因层面才能对症下药——如果 60% 的错误都是审题问题，那该练的是读题习惯，而不是继续刷题。

**复习机制**：遗忘曲线间隔 **10 分钟 → 1 → 2 → 4 → 7 → 15 → 30 天**
每次自评「仍不会 / 有点模糊 / 已掌握」会调整掌握度与下次复习时间。掌握度满 5 不再排入队列。

**统计**（「统计」标签页）：
- 错因分布（环形图）
- 知识点薄弱排行 Top 12
- 科目分布、难度分布
- **自动识别最需要补的薄弱知识点**（错多次且掌握度低），并可一键生成专项复习方案

### 背诵卡片

- AI 生成、错题转卡片、手动创建三种来源
- 一卡一知识点，正面问题、背面答案
- 间隔重复：`10 分钟 → 1 → 2 → 4 → 7 → 15 → 30 天`，答错退回第一级
- 复习时点卡片翻面，四档自评：完全忘了 / 想了一会儿 / 想起来了 / 太简单了

### 时间规划与提醒

三种作息模式，任选其一：

| 模式 | 说明 |
|---|---|
| **按周规划** | 周一到周日可分别设置不同作息 |
| **每日统一** | 一套作息用于每周选定的执行日 |
| **工作日/休息日分开** | 工作日与休息日各一套，可自定义哪天算工作日 |

**内置 4 套模板**一键套用：标准考研作息、在职/在校有课、强化期冲刺、假期全天。

每个时段可设置：类型（学习/复习/上课/休息/用餐/运动/睡眠）、科目、备注、**是否提醒**。

**提醒机制**：
- 到点弹窗（屏幕右下角常驻窗口，显示当前时段、剩余时间、下一项安排）
- 系统通知 + 提示音
- 支持**提前 N 分钟**提醒、**5 分钟后再说**、一键暂停
- 提醒由**主进程**驱动，窗口收进托盘也照常工作
- 也可以在对话里说「帮我制定学习计划」，AI 将它存入方案库作为**未启用草稿**，不覆盖当前计划、不自动提醒；检查后在时间规划页手动选用

**候选新增方案库**：支持新建空白方案、另存为副本、保存方案/名称、下拉选择并启用、删除当前方案（至少保留一个）。只有当前启用方案驱动提醒；删除当前方案会切换到剩余方案。支持跨午夜时段（如 `23:00–01:00`）及跨午夜提前提醒，同一日期、`planId` 与时段的提醒有防重保护。

工作日/休息日场景可互拷时段，副本有独立 id、名称不变；模板保存失败不显示成功，真实编辑器以 `isNew` 区分新建/已有项。矩阵结果以可滚动表格展示并保留原始文本。

### 专注监测（v2 候选）

「学习统计」中的专注监测**默认关闭，需用户主动开启**，且仅在当前计划的「学习 / 复习」时段统计；上课、休息及其他类型不计入。监测的是研来主窗口的前台/可见/最小化状态，不读取其他应用内容。提醒暂停与监测开关相互独立。

仅本地保存最多 **90 天的按日聚合**（窗口内/切屏时长、切屏次数、已结束专注段时长），并可选保存最多 **2000 条、90 天内的专注/切屏 session 记录**。每条记录包含 `{start, end, durationMs, kind, endReason}`，其中 `kind` 为 `focused` 或 `outOfWindow`，`endReason` 为 `switch`、`schedule`、`gap` 或 `stop`。旧版只有日聚合时仍可读取；记录不包含其他应用元数据。显示**近 7 天趋势**。关闭停止监测但保留既有数据；「清除统计」确认后清除聚合、session 记录与未结束专注段，不删除打卡记录、不改变开关。应用关闭、重载或休眠后的未观察间隔不会回填，窗口在前台不等于实际学习专注。

侧边导航在监测启用时显示「学习监测中」或等待时段指示，点击可回到学习统计；仪表盘显示最新 20 条切屏 session。历史学习统计来源/措辞已澄清，旧 UTC 日期桶不迁移或自动重解释为本地日期。

### 数学计算器（v2 候选）

左侧「数学计算器」打开的是**实际右侧计算侧栏**，可点「展开到主区域」使用完整视图。支持微积分、矩阵与微分方程，本地 SymPy 计算不调用 AI；结果可复制或插入当前对话（插入并不自动发送）。

Windows x64 内置 **CPython 3.13.12 + SymPy 1.14.0 + mpmath 1.3.0**，无需安装 Python，不含 Qt、numpy、matplotlib。**打开计算器即预热**，就绪后空闲 worker 常驻复用；空闲关闭侧栏/离开页面不卸载。取消计算（包括计算中离开页面）结束 worker，重启会替换 worker，真正退出应用结束 worker；收进托盘不是退出。历史仅在本次会话保留最多 20 条。其他平台不能据此视为具备已验证的同等内置运行时。

模式软键盘支持光标/选区插入、函数包裹选区及模板主体选中替换、退格和清空；用 `*` 表示乘法。矩阵编辑器支持 1–8 行/列、单位矩阵及多种操作表达式生成（不自动计算）；ODE 条件每行一条、最多 8 条，可用快捷按钮追加。各模式示例只填入，ODE 示例同时设置条件；用「计算 / 求解」或表达式/条件框中的 Ctrl / ⌘ + Enter 执行。详细限制与示例见 [使用手册](docs/USAGE.md#数学计算器)。矩阵软键盘 `^` 插入 `**`，ODE 不提供 `Abs` 默认模板；修正后的真实 worker 快捷输入 211/211 及 helper 11 项通过，不等于完整 GUI/桌面验收。

[worker 内存实测](docs/CALCULATOR-MEMORY.md)：就绪时工作集 **55.04 MiB** / 私有提交 **47.62 MiB**；代表性运算后空闲 15 秒 **60.77 / 52.13 MiB**。新 worker 就绪耗时示例约 **2.912 秒**，缓存未保证冷态，不是冷启动性能保证。数字仅为该机器单次 worker 采样，不是整个应用内存/峰值；性能随硬件、缓存、负载及运算变化。

## 检查更新

### 怎么用

- **启动时自动检查**：启动约 6 秒后后台静默检查，发现新版本才弹窗提示
- **手动检查**：设置 → **检查更新** → 「检查更新」按钮；托盘菜单和帮助菜单也有入口
- **版本历史**：查看该仓库所有 Release 与更新说明

发现新版本时，弹窗会显示版本对比、可下载文件（含文件大小与下载次数）、更新说明，并提供三个操作：
**跳过此版本**（记住选择，该版本不再提示）/ **稍后再说** / **前往下载**。

### 为什么默认走镜像

GitHub 官方 API 在国内常被限速或阻断。研来默认走**公共加速镜像**，并会在多个镜像间**自动回退**：

| 镜像 | 说明 |
|---|---|
| `gh-proxy.com` | 长期稳定，默认首选 |
| `ghfast.top` | 备用线路 |
| `gh.llkk.cc` | 备用线路 2 |
| `github.moeyy.xyz` | 备用线路 3 |
| GitHub 官方直连 | 网络能连上 GitHub 时可用 |

首选线路失败会自动尝试其余线路，不需要手动切换。每次检查都会显示实际生效的来源。

### 三种检查源

在设置中可切换：

1. **镜像加速（推荐）** —— 自动尝试多个公共线路
2. **GitHub 官方直连** —— 直接访问 `api.github.com`
3. **自定义代理前缀** —— 填你自己的反代地址（形如 `https://your.proxy/`）

### 关于「使用系统代理」

**默认关闭，这是有意的。**

更新请求发往公共镜像，这些镜像在国内可直连；而**继承系统代理反而更容易失败**——本机实测发现，当 Clash 类工具的节点异常时，走系统代理的请求全部报 `ERR_CONNECTION_CLOSED`，直连却正常。

所以默认绕过系统代理。仅当你的机器**完全没有直连通道**、只能靠代理出网时，才需要打开这个开关。

> 这个判断来自实测而非猜测：在开发机上，Electron 默认会话继承系统代理（本地 Clash），
> 而同样的 URL 用 `curl` 直连是成功的。详见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 省 token 设计

长对话最贵的是每轮重发整段历史。研来在**不削减功能、不改变界面显示**的前提下，用五套机制压制消耗：

| 机制 | 做法 | 效果 |
|---|---|---|
| **知识库按需注入** | 检索结果只存在于当轮请求，**不写回历史** | 40 轮对话只付一次检索的代价 |
| **图片自动衰减** | 只有最近几轮的截图真发送图片数据，更早的换成文字占位符 | 一张截图约 780 token，衰减后近 0 |
| **工具输出摘要化** | 超出近期窗口的工具原始返回压缩成一行摘要，保留文件引用 | 检索/绘图原始返回常达数千字 |
| **本地抽取式摘要** | 旧对话用本地算法提取标题与核心句，**不调用付费摘要接口** | 摘要本身也零成本 |
| **历史轮数上限** | 超出设定轮数的对话进入摘要区，而非整段保留 | 可调（默认 10 轮） |

**完全不消耗 token 的操作**：
本地知识库检索 · 错题本检索 · 对话标题生成 · 图片衰减与摘要 · 绘图渲染 · 公式排版 · 错因自动归类 · 全部统计图表

设置页（**省 token** 标签）可查看累计消耗与被压缩量，所有阈值可调，也可一键关闭。

## 常见问题

**Q：应用能打开，但发消息没反应？**
A：还没配模型。设置 → 模型与 API 填好并点「测试连接」通过。

**Q：粘贴的图片它说看不到？**
A：当前模型不支持视觉输入。换 `gpt-4o` / `qwen-vl-max` / `glm-4v` 这类多模态模型。

**Q：导入 PDF 后检索不到内容？**
A：可能是扫描版 PDF（没有文字层）。在知识库页查看该资料，若提示无法提取文字，请改传图片。

**Q：检查更新一直失败？**
A：设置 → 检查更新里展开「各线路尝试结果」看具体原因。若全部失败，可改用「GitHub 官方直连」，或打开「使用系统代理」。若提示「仓库暂无 Release」，说明该版本还没发布。

**Q：关闭窗口后应用去哪了？**
A：**首次**点关闭会弹窗询问「退出研来 / 最小化到系统托盘」，可勾选「记住我的选择，下次不再询问」（默认不勾选）。选择最小化或记住该选项后，窗口收进右下角托盘、提醒照常工作，点托盘图标恢复窗口；选「退出研来」则完全结束程序。随时可在设置 → 时间规划 → 「关闭窗口时」改回「每次询问」。

**Q：怎么让回答更贴合我的要求？**
A：设置 → 辅导行为 → 自定义系统提示词，例如「我在准备跨专业考研，基础薄弱，请尽量补充前置知识；公式推导请不要跳步」。

**Q：数据会丢吗？**
A：不会。数据都在本机，卸载时也**不会删除**你的对话、错题与知识库。建议定期在设置 → 数据里导出备份。

## 版本管理

采用 `MAJOR.MINOR.PATCH`，其中 PATCH 固定两位：

| 类型 | 规则 | 示例 |
|---|---|---|
| **小改动** | 最低位 +1 | `1.0.00` → `1.0.01` |
| **大改动** | 第二位 +1，最低位归零 | `1.0.05` → `1.1.00` |
| **重大改动** | 最高位 +1，其余归零 | `1.4.02` → `2.0.00` |

```bash
npm run version:bump patch   # 小改动
npm run version:bump minor   # 大改动
npm run version:bump major   # 重大改动
npm run version:bump --show  # 查看当前版本与三个候选
```

脚本会同步更新 `package.json`、`src/lib/prompts.ts` 的 `APP_VERSION` 与 README 徽章。

> 注意：`1.0.00` 不是合法 semver，electron-builder 会把它规范成 `1.0.0`。
> 因此打包入口 `scripts/dist.mjs` 通过 `APP_VERSION` 环境变量传递原始版本号，保证安装包文件名与界面显示一致。

## 隐私与安全

**所有数据都在本机**：设置、对话、错题本、卡片、知识库索引存放在本地 IndexedDB 与 `%APPDATA%\研来`。
除你配置的模型接口、TTS 接口和更新检查外，应用不会向任何第三方发送内容。

**安全设计**：
- 渲染进程**无 Node 权限**，全部系统能力经 `contextBridge` 显式暴露
- 数学表达式用**手写解析器**，不使用 `eval` / `new Function`
- 导出的 HTML 对用户与模型内容做转义
- CSP 限制脚本来源；外部链接交由系统浏览器打开
