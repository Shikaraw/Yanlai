## 完成一次配置

启动后只需做一次：

1. 点左下角 **齿轮**，或按 <kbd>Ctrl</kbd>+<kbd>,</kbd>
2. 进入 **模型与 API**
3. 选择服务预设，或手动填写 **Base URL**、**API Key**、**模型名称**
4. 点 **测试连接** —— 显示「连接成功」即可
5. （推荐）在 **默认备考科目** 里选你的科目，新建对话时会带上，术语更贴合

> 若测试连接失败：401 = Key 错误；404 = Base URL 路径不对（通常要以 `/v1` 结尾）；
> 429 = 余额不足或限流。

**建议**：如果要**截图讲题**，模型需支持视觉。可在设置里确认「视觉能力」为开启状态。

## 日常使用流程

一个典型的备考日：

| 时间 | 做什么 | 用什么 |
|---|---|---|
| 早上 | 看今天的计划 | 时间规划页（会自动弹提醒） |
| 做题时 | 遇到不会的题 | 截图 → 「讲解题目」模式 |
| 做错时 | 把错题和你的解法发来 | 「错题分析」模式 → 自动记入错题本 |
| 睡前 | 复习到期错题 + 背卡片 | 错题本「复习」标签 + 背诵卡片 |
| 周末 | 复盘一周、出一份模拟卷 | 「复盘总结」+「按题型出整卷」 |

## 把题目发给我：输入方式

### 1. 截图（最快）

1. <kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> 截图
2. 回到研来，在输入框按 <kbd>Ctrl</kbd>+<kbd>V</kbd>
3. 缩略图出现在输入框上方 → 直接发送

也可以点输入框左侧的**图片按钮**尝试读取剪贴板。

### 2. 拖入文件

把 PDF / Word / 图片直接**拖进窗口**，支持多文件。

### 3. 选择文件

点输入框左侧的**回形针**按钮选择文件。

### 4. 直接打字

公式可以用 LaTeX 写，例如 `求 lim_{x→0} (sin x - x)/x^3`。
也可以直接说「这道极限题为什么不能用洛必达」，研来会先确认理解再回答。

### 附件说明

- **图片**：直接发给视觉模型读取
- **文本类**（txt/md/csv）：内容会被读取
- **PDF/Word/Excel**：自动提取文字；扫描版 PDF 提不出文字时会提示你改用图片

## 十二种模式怎么选

底部功能条，点击切换。**选对模式能显著改善回答质量。**

### 讲解类

**讲解题目** —— 最常用。发题目，得到六段式讲解：
考点识别 → **思路先行** → 分步推导 → 易错提醒 → 知识点回扣 → 变式检验。

> 💡 **如果你已经做过**：把题目 + 你的解答一起发来，选择 **错题分析** 模式效果更好。

**错题分析** —— 发错题 + 你的错解 + 正确答案。研来会：
定位第一个出错的步骤 → 归类错因 → 给正解 → **分析你在哪个岔路口走错了** → 给通用方法 → 记入错题本。

**长难句/翻译** —— 英语。断句、找主干、画结构树、直译+润色、点出命题方式。

**自由问答** —— 不确定用哪个时选它。研来会先判断你的意图。

### 练习类

**类比出题** —— 给一道题，要 5 道同源变式。会标明哪些与原题完全同构（最值得优先做）。

**按题型出整卷** —— 说「按 408 真题题型出一份完整模拟卷」，会得到：
考试说明 → 试题 → 分隔线 → 参考答案与解析 → 考点分布与难度表。

**作文批改** —— 英语作文、政治大题、专业课论述。按考研评分档打分，逐句精批表格，给保留你风格的提分版。

### 整理类

**总结大纲** —— 层级大纲 + 重要度星级（★★★必考）+ 考频 + 学习顺序 + 时间分配建议。

**整理知识点** —— 每块含：定义 → 条件与适用范围 → 公式 → 直觉解释 → 典型用法 → 常见错误 → 记忆锚点。

**背诵卡片** —— 把内容拆成一卡一知识点的问答卡片，自动进入复习队列。

### 规划类

**学习计划** —— 告诉它离考试多久、每天几小时、各科水平，会产出分阶段计划，
并且**可以直接写入时间规划模块**（说「把计划写进时间规划」）。

**复盘总结** —— 读取你的错题数据，按**提分收益**排序薄弱点，给遗忘曲线复习安排，
区分「该放弃的」和「该死磕的」。

## 知识库怎么用

**目的**：让回答基于**你的资料**，而不是模型的泛化知识，并标注出处。

### 导入

在「知识库」页：
- **拖入**文件或文件夹，或点「导入资料」
- **导入文件夹**：选一个目录，递归导入其中所有资料（子文件夹一并收录）。
  适合把一个章节、一整本书、或从别处下载的资料包一次性导入。
- 或切到「粘贴文本」标签，直接贴笔记（适合课堂笔记）
- 或在「工作区」页对某个文件点数据库图标

**批量导入命令行**（适合超大资料包或脚本化部署）：

```bash
# 导入整个目录；--import-kb-exit 让应用导入完成后自动退出
yanlai --import-kb "D:\资料\考研数学" --subject 考研数学 --import-kb-exit

# 先清空知识库再导入（只清知识库，对话与错题本不受影响）
yanlai --import-kb "D:\资料\考研数学" --subject 考研数学 --import-kb-replace --import-kb-exit
```

导入完成后「资料」页会列出每份资料及其片段数；点行尾的眼睛图标可查看已提取的文本。

### 验证是否可检索

切到「检索测试」标签，输入关键词看能否命中。若命不中，说明资料没被正确索引
（最常见原因：扫描版 PDF 无文字层）。

### 让 AI 整理

在「整库问答」标签有几个常用操作按钮：

- 整理成考纲式知识点大纲
- 提取核心公式清单
- **找出资料之间的矛盾与缺口**
- 生成背诵卡片

## 错题本怎么用

### 自动记录

当你在对话里提交**自己做错的解答**时，研来会自动记录，无需手动操作。

### 三个标签页

| 标签 | 用途 |
|---|---|
| **错题列表** | 筛选、搜索、编辑、删除；点开可看错解/正解/错因，并做复习自评 |
| **复习** | 按遗忘曲线抽出今日到期的错题，先自己做再看答案 |
| **统计** | 错因分布、知识点薄弱排行、科目分布、**自动识别最该补的知识点** |

### 筛选用法

- 按**错因**筛选：看「审题错误」有多少道 → 判断该练读题而非刷题
- 按**知识点**筛选：专项突破
- 按**掌握度**排序：优先处理最不熟练的

### 复习自评

三个按钮分别代表：**仍不会** / **有点模糊** / **已掌握**。
- 「仍不会」→ 掌握度 -1，间隔缩短
- 「已掌握」→ 掌握度 +2，间隔延长
- 掌握度满 5 不再排入队列，但保留在错题本可随时查阅

### 手动添加

点右上「手动添加」可自己录入。**错因类别**留空时会根据错因文字自动匹配。

## 时间规划怎么用

### 三种模式

| 模式 | 适合 |
|---|---|
| **按周规划** | 每天不一样（如有课的日子） |
| **每日统一** | 每天都一样 |
| **工作日/休息日分开** | 平时在校/上班，周末全天 |

### 快速开始

1. 选模式
2. 若列表为空，会显示 **4 套模板** —— 点一个套用
3. 逐条微调（点时段卡片可编辑）
4. 不需要提醒的时段，点右侧铃铛图标关闭

### 让 AI 制定

点右上 **AI 制定计划**，或直接在对话里说：

> 帮我制定考研学习计划。我每天能学 8 小时，数学基础较弱，专业课是 408。

研来会把计划**直接写入**这个模块，之后到点自动提醒。

### 提醒行为

到点时：
- 屏幕右下角弹出提醒窗口（显示当前时段、剩余时间、下一项）
- 系统通知 + 提示音

可以：
- **5 分钟后再说** —— 延后提醒
- 点铃铛图标（标题栏下方）暂停全部提醒
- 设置 → 提醒 里配置提前量、是否弹窗/通知/提示音

> 窗口收进系统托盘后提醒**照常工作**（调度器在主进程运行）。

## 朗读怎么用

### 配置

设置 → 朗读 → 选引擎：

- **系统内置语音**（免费离线）—— Windows 已安装的语音包，中文通常有 Microsoft Huihui
- **自定义 TTS API** —— 需填 Base URL、Key、模型、音色
- **浏览器语音合成** —— 网页预览环境用

### 自动朗读

三档可选：
- **关闭** —— 只在你点「朗读」按钮时读
- **边输出边朗读** —— 句子生成完立即开始（延迟最低）
- **输出完朗读** —— 整段结束后再读

### 使用技巧

- 每条回复下方有独立「朗读」按钮，随时可停
- 朗读会自动跳过代码块
- 公式会用中文读法：`\frac{a}{b}` 读作「b 分之 a」

## 导出与预览

### 导出

每条回复下方有 **Word** 按钮；点旁边的 `∨` 更多菜单可选 PDF / Markdown / HTML。

文件保存到工作区，同时在对话里出现卡片：
- 点 **文件夹图标** = 在资源管理器中定位
- 点 **外链图标** = 用系统程序打开
- 点 **眼睛图标** = 在右侧预览面板中查看

### 预览面板

- 标题栏的 **眼睛按钮** 开关预览面板
- 四个标签：**预览**（当前文件）/ **工作区**（文件浏览）/ **知识库**（资料列表）
- 对话里的图片点击可直接放大预览

### 窗口置顶

点标题栏的**图钉按钮**让窗口始终置顶 —— 对照阅读纸质资料时很有用。

## 学习统计

「学习统计」页包含：

- **头部指标**：今日学习、连续打卡、错题掌握、卡片牢固率
- **近 14 天学习时长**：柱状趋势 + 日均/最长/有效天数
- **今日计划执行**：环形进度 + 当前时段 + 时段列表
- **错因结构**：环形图，看错误主要来自哪一环
- **知识点薄弱排行** Top 10
- **各科投入 / 辅导使用情况 / 建议**

底部「生成复盘」按钮会切到对话页，让 AI 基于这些数据给调整建议。

## 让回答更符合你的需求

设置 → **辅导行为** → 自定义系统提示词。例如：

```
我在准备跨专业考研，基础薄弱，请尽量补充前置知识；
公式推导请不要跳步；
我容易混淆充分条件和必要条件，遇到相关的点请特别提醒我。
```

也可以调整：
- **工具开关** —— 关掉后 AI 只能用文字回答
- **自动检索知识库** —— 关掉后只在明确要求时检索
- **工具调用轮数** —— 影响能完成多复杂的多步任务

## 省 token 与成本控制

设置 → **省 token** 页可看到：
- 累计消耗 token（按服务端返回的真实用量）
- 已压缩内容估算量
- 五项省 token 机制的说明

可调阈值：
- **保留完整细节的最近轮数**（默认 10）
- **检索片段数量上限**（默认 4）
- **检索片段字符预算**（默认 3200）
- **是否淘汰旧图片 / 摘要化旧工具输出**

**成本参考**（以 DeepSeek 为例）：一道题的完整讲解大约消耗 2000-6000 token，
按现行价格约 ¥0.01-0.03。一天问 20 道题约 ¥0.2-0.6。

**想完全免费**：用本地 Ollama。装好后 `ollama pull qwen2.5:14b`，
Base URL 填 `http://127.0.0.1:11434/v1`，Key 随便填。14B 以上做考研数学讲解基本够用。

## 检查更新

- **启动时自动检查**：约 6 秒后后台检查，发现新版本才提示
- **手动检查**：设置 → 检查更新；托盘菜单也有入口
- **版本历史**：查看该仓库所有 Release

**发现新版本时**可以选择：
- **跳过此版本** —— 该版本不再提示（可在设置里恢复）
- **稍后再说**
- **前往下载** —— 通过镜像或官方地址下载

若检查失败，展开「各线路尝试结果」看具体原因：
- 全部失败 → 换成「GitHub 官方直连」，或打开「使用系统代理」
- 「仓库暂无 Release」→ 正常状态，说明还没发布

## 数据管理

### 存放位置

| 内容 | 位置 |
|---|---|
| 设置（含 API Key） | `%APPDATA%\研来\settings.json` |
| 对话 / 错题 / 卡片 / 知识库索引 | 本机 IndexedDB |
| 资料原文与附件 | `%APPDATA%\研来\kb`、`attachments` |
| 生成的文件 | 工作区目录 / `%APPDATA%\研来\exports` |
| 日志 | `%APPDATA%\研来\logs` |

### 备份

设置 → 数据 → **导出全部数据备份**，会生成一个 JSON（**不含** API Key）。

### 清理

同页「危险操作」区域可分别清空：对话 / 错题本 / 知识库 / 恢复默认设置。

> 卸载应用时**不会**删除你的数据。

### 设置工作区

设置 → 工作区 → 选择目录。AI 生成的文件都保存到这里，AI 也能读取这里的资料。

## 遇到问题

| 现象 | 原因与解决 |
|---|---|
| 发消息无反应 | 未配置模型 → 设置 → 模型与 API |
| 提示「请求失败」 | 看错误信息：401 Key 错 / 404 路径错 / 429 余额或限流 |
| 图片识别不了 | 模型不支持视觉 → 换 `gpt-4o` / `qwen-vl-max` / `glm-4v` |
| 知识库检索不到 | 扫描版 PDF → 改传图片；或用「检索测试」验证 |
| 更新检查失败 | 切换更新源，或打开「使用系统代理」 |
| 关闭窗口后找不到应用 | 已最小化到托盘 → 点右下角托盘图标 |
| 想彻底退出 | 托盘右键 → 退出研来 |
| 不想每次关闭都弹窗询问 | 弹窗里勾选「记住我的选择」，或到设置 → 时间规划 → 「关闭窗口时」改为「最小化到托盘」/「直接退出」 |

需要排查细节时，设置 → 数据 → **打开日志**。
