## 完成一次配置

启动后只需做一次：

1. 点左下角 **齿轮**，或按 <kbd>Ctrl</kbd>+<kbd>,</kbd>
2. 进入 **模型与 API**
3. 选择服务预设，或手动填写 **Base URL**、**API Key**、**模型名称**
4. 点 **测试连接** —— 显示「连接成功」即可
5. （推荐）在 **默认备考科目** 里选你的科目，新建对话时会带上，术语更贴合

> 若测试连接失败：401 = Key 错误；404 = Base URL 路径不对（通常要以 `/v1` 结尾）；
> 429 = 余额不足或限流。

**建议**：如果要**截图讲题**，模型需支持视觉。可在设置里确认「视觉能力」为开启状态。

## 把题目发给我：输入方式

### 1. 截图（最快）

1. <kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> 截图
2. 回到研来，在输入框按 <kbd>Ctrl</kbd>+<kbd>V</kbd>
3. 缩略图出现在输入框上方 → 直接发送

也可以点输入框左侧的**图片按钮**尝试读取剪贴板。

### 2. 拖入文件

把 PDF / Word / 图片直接**拖进窗口**，支持多文件。

### 3. 选择文件

点输入框左侧的**回形针**按钮选择文件。

### 4. 直接打字

公式可以用 LaTeX 写，例如 `求 lim_{x→0} (sin x - x)/x^3`。
也可以直接说「这道极限题为什么不能用洛必达」，研来会先确认理解再回答。

### 附件说明

- **图片**：直接发给视觉模型读取
- **文本类**（txt/md/csv）：内容会被读取
- **PDF/Word/Excel**：自动提取文字；扫描版 PDF 提不出文字时会提示你改用图片

## 十二种模式怎么选

底部功能条，点击切换。**选对模式能显著改善回答质量。**

### 讲解类

**讲解题目** —— 最常用。发题目，得到六段式讲解：
考点识别 → **思路先行** → 分步推导 → 易错提醒 → 知识点回扣 → 变式检验。

> 💡 **如果你已经做过**：把题目 + 你的解答一起发来，选择 **错题分析** 模式效果更好。

**错题分析** —— 发错题 + 你的错解 + 正确答案。研来会：
定位第一个出错的步骤 → 归类错因 → 给正解 → **分析你在哪个岔路口走错了** → 给通用方法 → 记入错题本。

**长难句/翻译** —— 英语。断句、找主干、画结构树、直译+润色、点出命题方式。

**自由问答** —— 不确定用哪个时选它。研来会先判断你的意图。

### 练习类

**类比出题** —— 给一道题，要 5 道同源变式。会标明哪些与原题完全同构（最值得优先做）。

**按题型出整卷** —— 说「按 408 真题题型出一份完整模拟卷」，会得到：
考试说明 → 试题 → 分隔线 → 参考答案与解析 → 考点分布与难度表。

**作文批改** —— 英语作文、政治大题、专业课论述。按考研评分档打分，逐句精批表格，给保留你风格的提分版。

### 整理类

**总结大纲** —— 层级大纲 + 重要度星级（★★★必考）+ 考频 + 学习顺序 + 时间分配建议。

**整理知识点** —— 每块含：定义 → 条件与适用范围 → 公式 → 直觉解释 → 典型用法 → 常见错误 → 记忆锚点。

**背诵卡片** —— 把内容拆成一卡一知识点的问答卡片，自动进入复习队列。

### 规划类

**学习计划** —— 告诉它离考试多久、每天几小时、各科水平，会产出分阶段计划。
说「把计划写进时间规划」会**保存为方案库中的未启用草稿**；当前方案不变，不自动触发提醒，需你检查后手动选用。

**复盘总结** —— 读取你的错题数据，按**提分收益**排序薄弱点，给遗忘曲线复习安排，
区分「该放弃的」和「该死磕的」。

## 知识库怎么用

**目的**：让回答基于**你的资料**，而不是模型的泛化知识，并标注出处。

### 导入

在「知识库」页：
- **拖入**文件或文件夹，或点「导入资料」
- **导入文件夹**：选一个目录，递归导入其中所有资料（子文件夹一并收录）。
  适合把一个章节、一整本书、或从别处下载的资料包一次性导入。
- 或切到「粘贴文本」标签，直接贴笔记（适合课堂笔记）
- 或在「工作区」页对某个文件点数据库图标

**批量导入命令行**（适合超大资料包或脚本化部署）：

```bash
# 导入整个目录；--import-kb-exit 让应用导入完成后自动退出
yanlai --import-kb "D:\资料\考研数学" --subject 考研数学 --import-kb-exit

# 先清空知识库再导入（只清知识库，对话与错题本不受影响）
yanlai --import-kb "D:\资料\考研数学" --subject 考研数学 --import-kb-replace --import-kb-exit
```

导入完成后「资料」页会列出每份资料及其片段数；点行尾的眼睛图标可查看已提取的文本。

### 验证是否可检索

切到「检索测试」标签，输入关键词看能否命中。若命不中，说明资料没被正确索引
（最常见原因：扫描版 PDF 无文字层）。

### 让 AI 整理

在「整库问答」标签有几个常用操作按钮：

- 整理成考纲式知识点大纲
- 提取核心公式清单
- **找出资料之间的矛盾与缺口**
- 生成背诵卡片

## 错题本怎么用

### 自动记录

当你在对话里提交**自己做错的解答**时，研来会自动记录，无需手动操作。

### 三个标签页

| 标签 | 用途 |
|---|---|
| **错题列表** | 筛选、搜索、编辑、删除；点开可看错解/正解/错因，并做复习自评 |
| **复习** | 按遗忘曲线抽出今日到期的错题，先自己做再看答案 |
| **统计** | 错因分布、知识点薄弱排行、科目分布、**自动识别最该补的知识点** |

### 筛选用法

- 按**错因**筛选：看「审题错误」有多少道 → 判断该练读题而非刷题
- 按**知识点**筛选：专项突破
- 按**掌握度**排序：优先处理最不熟练的

### 复习自评

三个按钮分别代表：**仍不会** / **有点模糊** / **已掌握**。
- 「仍不会」→ 掌握度 -1，间隔缩短
- 「已掌握」→ 掌握度 +2，间隔延长
- 掌握度满 5 不再排入队列，但保留在错题本可随时查阅

### 手动添加

点右上「手动添加」可自己录入。**错因类别**留空时会根据错因文字自动匹配。

## 时间规划怎么用

### 三种模式

| 模式 | 适合 |
|---|---|
| **按周规划** | 每天不一样（如有课的日子） |
| **每日统一** | 每天都一样 |
| **工作日/休息日分开** | 平时在校/上班，周末全天 |

### 快速开始与方案管理（v2 候选）

1. 在顶部「选用方案」下拉框选择方案，**选择即启用**；提醒只使用当前启用方案。
2. 「新建空白方案」用于另起计划，「另存为」保存当前内容的副本。
3. 选三种规划模式之一；列表为空时可套用 4 套模板，点时段卡片微调。
4. 修改「方案名称」后点「保存方案 / 名称」；时段编辑、模式与执行日变更会直接保存到当前方案。
5. 不需要提醒的时段，点右侧铃铛关闭。「删除当前方案」需确认，删除后切换至剩余方案；至少保留一个，最后一个不能删除。

支持跨午夜时段，例如 `23:00–01:00` 结束于次日；凌晨仍可显示昨天开始的进行中时段。每日统一模式的执行日仅适用于统一作息，按周和工作日模式各自按日期选择时段。

工作日/休息日模式下，时段可复制到另一场景（工作日 ↔ 休息日）；副本有独立时段 id、名称保持不变，源场景不受影响。按周复制仍使用选择目标日的弹窗，源日禁用。

模板套用、场景复制与编辑保存失败时不会显示成功提示；请先解决错误再重试。新增/已有时段通过明确的 `isNew` 身份区分，新增不会误用已有编辑身份。

### 让 AI 制定

点右上 **AI 制定计划**，或直接在对话里说：

> 帮我制定考研学习计划。我每天能学 8 小时，数学基础较弱，专业课是 408。

研来会把计划存入方案库作为**新的未启用草稿**，即使这是第一个 AI 方案也不会自动启用。
现有计划不被覆盖，也不因草稿而自动提醒。到「时间规划」检查后，通过「选用方案」下拉框手动选用，再微调执行日、时段与提醒设置。

### 提醒行为

到点时：
- 屏幕右下角弹出提醒窗口（显示当前时段、剩余时间、下一项）
- 系统通知 + 提示音

可以：
- **5 分钟后再说** —— 延后提醒
- 点铃铛图标（标题栏下方）暂停全部提醒
- 设置 → 提醒 里配置提前量、是否弹窗/通知/提示音

> 窗口收进系统托盘后提醒**照常工作**（调度器在主进程运行）。

## 数学计算器

此功能纳入 v2.0.00；正式构建与发布状态见验证记录，当前内置运行时针对 **Windows x64**。

1. 点击左侧「数学计算器」，打开**实际右侧计算侧栏**，同时预热内置 Python/SymPy；无需先按计算。首次打开可见「正在预热 Python」，就绪后显示「Python 已就绪」。
2. 点「展开到主区域」切换完整视图。关闭侧栏/离开计算器在空闲时只关闭界面，**不卸载 worker**；若仍有计算在进行，离开会取消该请求并结束 worker。
3. 选择 **微积分 / 矩阵 / 微分方程**。各模式保留本次会话表达式草稿，软键盘按模式显示按键，可展开/收起。
4. 直接输入，或用软键盘在当前光标处插入、替换选区。函数/积分/求导模板包裹选中文字；没有选区时填入占位表达式，模板主体会选中供替换。退格删除选区或光标前字符，「清空表达式」清空输入；乘法用 `*`。表达式最多 2048 字符，过长模板插入整体拒绝，不截断括号。
5. 矩阵模式的编辑器支持 **1–8 行/列**，空格按 `0`，单元格为最多 128 字符的数学表达式。可填单位矩阵（仅方阵），生成矩阵、行列式、求逆、转置、秩、迹、行最简或特征值表达式；这些按钮**替换表达式但不自动计算**。行列式/求逆/迹/特征值需方阵，求逆还需可逆。矩阵幂手动使用 `**`；软键盘 `^` 同样插入 `**`（修正后真实 worker 检查通过）。
6. ODE 使用 `y'`、`y''` 等记号；初值可留空，每行一条，最多 8 条、每条最多 2048 字符，条件框总长最多 4096 字符。快捷条件 `y(0)=1`、`y(0)=0`、`y'(0)=0`、`y'(0)=1` 追加到条件框，不自动求解。ODE 不提供 `Abs` 默认模板，该修正已通过真实 worker 快捷输入复跑。
7. 各模式提供「示例 · …」按钮，仅填入、不自动计算；ODE 示例同时替换初值条件。微积分含定积分、求导、二阶导数、化简；矩阵含求逆、行列式、行最简；ODE 含一阶初值、二阶初值、非齐次。
8. 点「计算 / 求解」，或在表达式/条件框按 <kbd>Ctrl</kbd>+<kbd>Enter</kbd>（界面也支持 <kbd>⌘</kbd>+<kbd>Enter</kbd>；不代表其他平台运行时已验证）。矩阵结果以带行列编号的可滚动表格显示，并保留原始文本。
9. 结果可「复制到对话」或「插入当前对话」，插入只预填输入框，**不会自动发送给模型**。计算本身不调用 AI。

示例：`∫(x^2, x, 0, 1)` → `1/3`；`inverse([[1,2],[3,4]])` → `[[-2,1],[3/2,-1/2]]`；`y'+y=0`（初值 `y(0)=1`）。也可填二阶示例 `y''+y=0`，条件为 `y(0)=0` 与 `y'(0)=1` 后手动求解。

内置 **CPython 3.13.12、SymPy 1.14.0、mpmath 1.3.0**，不要求系统 Python，不含 Qt、numpy、matplotlib。未打开计算器时不因普通聊天预启动；打开即预热，就绪后空闲常驻复用。**取消计算会结束 worker**，重启引擎会结束旧 worker 后重新预热，真正退出应用会结束 worker；关闭窗口到托盘不等于退出，空闲 worker 仍可常驻。本次会话历史最多 20 条，不保存磁盘计算历史。

[内存与性能实测](CALCULATOR-MEMORY.md)：worker 就绪时工作集 **55.04 MiB** / 私有提交 **47.62 MiB**；代表性运算后空闲 15 秒仍为 **60.77 / 52.13 MiB**，空闲不会自动释放 Python/SymPy。新 worker 就绪耗时示例约 **2.912 秒**，不是保证的冷启动时间（文件/杀毒缓存未保证冷态）。这些是该机器单次进程采样，不是整个 Electron 应用内存、峰值或性能承诺，硬件、缓存、负载与表达式复杂度都会影响结果。

**新包定向桌面检查通过**：实际隔离启动后，打开计算器前无 Python，打开后首次计算前已 ready；空闲关闭/重开侧栏及展开主区域仍复用同一 worker。求导示例返回 `cos(x)`，清空后软键盘定积分模板返回 `1/3`。矩阵编辑器点单位矩阵→行列式生成 `det([[1,0],[0,1]])`，不会自动计算；点击计算返回 `1`。ODE 二阶初值按钮填入 `y''+y=0` 和 `y(0)=0`、`y'(0)=1`，点击计算返回 `y=sin(x)`。侧栏/展开布局已截图检查。通过原生关闭对话选择「退出研来」正常退出，启动任务退出码 **0**；`Get-CimInstance` 仅查询本次 owned 主进程 PID `77316` 和 worker PID `67708`，两者均无结果，**正常退出释放 worker 已验证**。此为定向检查，**完整输入法、GUI 取消、全部尺寸及 NSIS 实装未覆盖**；生命周期实现及自动化覆盖不等于其余 GUI 流程已经验收。

> 本轮浏览器 GUI 已观察模板主体选中替换、函数嵌套、矩阵单位矩阵后行列式生成 `det([[1,0],[0,1]])`、ODE 二阶初值示例填入表达式和两条条件。Ctrl+A 组合未成功投递/未选中，不宣称 GUI 全选包裹通过，也不视为已证明的应用失败。真实 worker 快捷输入修正后 **211/211**、helper **11 项**通过；自动化及上述定向检查不代表完整桌面验收。旧 GUI 布局复测与旧 ready 便携版验收仍仅对当时功能有效。CleverCalculator 原始源码未附独立许可证，但权利人已明确确认所有权并授权公开发布集成源码与二进制，源码再分发门禁已解决；不新设 MIT 许可证，第三方许可证与 notices 保留并继续适用。

## 朗读怎么用

### 配置

设置 → 朗读 → 选引擎：

- **系统内置语音**（免费离线）—— Windows 已安装的语音包，中文通常有 Microsoft Huihui
- **自定义 TTS API** —— 需填 Base URL、Key、模型、音色
- **浏览器语音合成** —— 网页预览环境用

### 自动朗读

三档可选：
- **关闭** —— 只在你点「朗读」按钮时读
- **边输出边朗读** —— 句子生成完立即开始（延迟最低）
- **输出完朗读** —— 整段结束后再读

### 使用技巧

- 每条回复下方有独立「朗读」按钮，随时可停
- 朗读会自动跳过代码块
- 公式会用中文读法：`\frac{a}{b}` 读作「b 分之 a」

## 学习统计

「学习统计」页包含：

- **头部指标**：今日学习、连续打卡、错题掌握、卡片牢固率
- **近 14 天学习时长**：柱状趋势 + 日均/最长/有效天数
- **今日计划执行**：环形进度 + 当前时段 + 时段列表
- **错因结构**：环形图，看错误主要来自哪一环
- **知识点薄弱排行** Top 10
- **各科投入 / 辅导使用情况 / 建议**

底部「生成复盘」按钮会切到对话页，让 AI 基于这些数据给调整建议。

### 专注监测（v2 候选，默认关闭）

在「学习统计」的「专注监测」卡片点「开启监测」或开关即可主动启用，随时可关闭。开关偏好保存在本机，关闭时不订阅窗口状态、不记录新的专注统计。启用后左侧导航显示「学习监测中」或「监测已启用 · 等待学习时段」指示，点击可回到学习统计。

- **范围**：仅当前启用计划的「学习 / 复习」时段；上课、休息、睡眠及其他类型不统计。时段需有有效且不相同的开始/结束时间，支持跨午夜。
- **含义**：前台且可见、未最小化的研来主窗口计为「窗口内」，否则计为「切屏时间」。从一次正时长窗口内专注段退出计一次切屏，重复失焦/最小化不额外计次。「平均一次专注」按已结束专注段计算，未结束或无法完整观察的片段不计入该平均值。
- **边界**：这是窗口状态统计，不证明实际学习质量，也不能识别你是否在其他应用学习；不会读取其他应用名称、内容或屏幕。
- **保存与趋势**：只保存本机最多 **90 天按日聚合**，并可选保存最多 **2000 条、90 天内的 session 记录**。每条包含 `{start, end, durationMs, kind, endReason}`；`kind` 是 `focused` 或 `outOfWindow`，`endReason` 是 `switch`、`schedule`、`gap` 或 `stop`。旧版只有聚合数据时仍可读取。显示**近 7 天窗口内分钟趋势**；session 记录只描述研来窗口的已观察状态，不包含其他应用元数据。应用重载、关闭、休眠或长时间暂停后的未观察间隔不回填。
- **独立开关**：「暂停提醒」不关闭专注监测；关闭监测不清除旧统计。
- **重置**：点「清除统计」并确认，删除所有专注日聚合、session 记录及未结束片段，无法恢复；不删除学习打卡、不改变监测开关。若仍开启，后续符合条件的时段继续记录。

仪表盘显示最新 20 条切屏 session，并澄清历史学习统计的来源/措辞；旧 UTC 日期桶不迁移、不自动重解释为本地日期。

**桌面验证边界**：旧 ready 便携版追加验收已在解锁环境观察统计、最小化/恢复、托盘隐藏/同 profile 恢复及退出重启持久化，用户确认统计功能。此前锁屏阻断已成为历史状态；这些观察不构成受控精确计时、全部托盘操作验收，也不覆盖本轮新包。最新 `release/v2-calculator-input-final` 的最终构建与计算器定向桌面检查已通过，正常退出释放 worker 已验证，不代表本轮全部桌面/统计行为已重新验收；完整输入法、GUI 取消、全部尺寸及 NSIS 实装未覆盖，不应为测试解锁用户机器。

**隔离检查配置**：桌面检查可设置 `YANLAI_INSPECTION_PROFILE` 为专用**绝对路径**。启动会在取得单实例锁前设置 `userData`，让检查配置/数据不写入常用用户目录；相对路径会报错。这只是用户配置隔离，不是系统沙箱。

## 省 token 与成本控制

设置 → **省 token** 页可看到：
- 累计消耗 token（按服务端返回的真实用量）
- 已压缩内容估算量
- 五项省 token 机制的说明

可调阈值：
- **保留完整细节的最近轮数**（默认 10）
- **检索片段数量上限**（默认 4）
- **检索片段字符预算**（默认 3200）
- **是否淘汰旧图片 / 摘要化旧工具输出**

**成本参考**（以 DeepSeek 为例）：一道题的完整讲解大约消耗 2000-6000 token，
按现行价格约 ¥0.01-0.03。一天问 20 道题约 ¥0.2-0.6。

**想完全免费**：用本地 Ollama。装好后 `ollama pull qwen2.5:14b`，
Base URL 填 `http://127.0.0.1:11434/v1`，Key 随便填。14B 以上做考研数学讲解基本够用。

## 检查更新

- **启动时自动检查**：约 6 秒后后台检查，发现新版本才提示
- **手动检查**：设置 → 检查更新；托盘菜单也有入口
- **版本历史**：查看该仓库所有 Release

**发现新版本时**可以选择：
- **跳过此版本** —— 该版本不再提示（可在设置里恢复）
- **稍后再说**
- **前往下载** —— 通过镜像或官方地址下载

若检查失败，展开「各线路尝试结果」看具体原因：
- 全部失败 → 换成「GitHub 官方直连」，或打开「使用系统代理」
- 「仓库暂无 Release」→ 正常状态，说明还没发布

## 数据管理

### 存放位置

| 内容 | 位置 |
|---|---|
| 设置（含 API Key） | `%APPDATA%\研来\settings.json` |
| 对话 / 错题 / 卡片 / 知识库索引 | 本机 IndexedDB |

同页「危险操作」区域可分别清空：对话 / 错题本 / 知识库 / 恢复默认设置。

> 卸载应用时**不会**删除你的数据。

### 设置工作区

设置 → 工作区 → 选择目录。AI 生成的文件都保存到这里，AI 也能读取这里的资料。

## 遇到问题

| 现象 | 原因与解决 |
|---|---|
| 发消息无反应 | 未配置模型 → 设置 → 模型与 API |
| 提示「请求失败」 | 看错误信息：401 Key 错 / 404 路径错 / 429 余额或限流 |
| 图片识别不了 | 模型不支持视觉 → 换 `gpt-4o` / `qwen-vl-max` / `glm-4v` |
| 知识库检索不到 | 扫描版 PDF → 改传图片；或用「检索测试」验证 |
| 更新检查失败 | 切换更新源，或打开「使用系统代理」 |
| 关闭窗口后找不到应用 | 已最小化到托盘 → 点右下角托盘图标 |
| 想彻底退出 | 托盘右键 → 退出研来 |
| 不想每次关闭都弹窗询问 | 弹窗里勾选「记住我的选择」，或到设置 → 时间规划 → 「关闭窗口时」改为「最小化到托盘」/「直接退出」 |

需要排查细节时，设置 → 数据 → **打开日志**。
